# WinPrepare — полная визуальная автоматизация Windows 11 после установки

Комплект скриптов, который **полностью автоматически** после чистой установки Windows 11 Enterprise (25H2):

1. **Запускает визуальное приложение на рабочем столе** сразу после автоматического входа пользователя в систему;
2. **Подключает Wi-Fi** `MRS.Mobile` (пароль `Mriya2023!`), поддерживая как WPA2-PSK, так и WPA3-SAE;
3. **Устанавливает ВСЕ обновления и ВСЕ драйверы**:
   - Обязательные обновления безопасности и качества (`BrowseOnly=0`);
   - Дополнительные обновления и драйверы устройств (`BrowseOnly=1`, `Type='Driver'`);
   - При необходимости ноутбук сам перезагружается, возвращается на рабочий стол, UI возобновляет работу и повторяет поиск, пока не останется 0 обновлений;
4. **Требует подключить корпоративную сеть**:
   - На экране появляется понятное требование переключить Wi-Fi на `Mrs.team` или подключить сетевой кабель;
   - Скрипт непрерывно пингует и опрашивает контроллер домена `rixos.rus` (ICMP, DNS, LDAP TCP 389);
   - **Пока связи с rixos.rus нет — кнопка ввода в домен заблокирована**;
5. **Вводит ПК в домен `rixos.rus` под текущим именем (не меняет имя ПК)**:
   - Как только контроллер доступен, администратор / пользователь вводит логин и пароль;
   - При случайной опечатке в пароле скрипт не вылетает, а даёт возможность ввести пароль заново;
   - ПК присоединяется к домену под именем, назначенным в `autounattend.xml`;
   - Скрипт очищает автозапуск, отключает `AutoAdminLogon` и отправляет ПК в финальную перезагрузку.

Всё построено на **встроенных средствах Windows** (WUA COM-объект `Microsoft.Update`, `netsh`, `Add-Computer`, WinForms) — **ничего стороннего из интернета не скачивается** (никаких PSGallery / PSWindowsUpdate / сторонних зеркал), поэтому санкции и ограничения провайдеров в РФ не мешают.

## Архитектура работы

```
autounattend.xml (Установка Win 11, ключ Enterprise, имя ПК, autologon)
   └─ SetupComplete.cmd (выполняется 1 раз при установке от SYSTEM)
        └─ Bootstrap.ps1:
             ├─ Отключение сна и гибернации (powercfg)
             ├─ Отключение P2P Delivery Optimization (DODownloadMode = 0, режим HTTP-only)
             ├─ Закрепление AutoAdminLogon = 1 (без лимита количества входов)
             └─ Регистрация задачи WinPrepare-App (Trigger: AtLogOn, RunLevel: Highest)
                  │
                  ▼ (Вход на рабочий стол)
        Main-UI.ps1 (Запускается прямо на рабочем столе с правами администратора):
          ├─ Шаг 1: Подключение к Wi-Fi MRS.Mobile -> проверка интернета
          ├─ Шаг 2: Центр обновления Windows:
          │     ├─ Поиск обязательных обновлений (BrowseOnly=0)
          │     ├─ Поиск дополнительных компонентов и всех драйверов (BrowseOnly=1)
          │     ├─ Автоматическое принятие лицензий EULA
          │     ├─ Скачивание и установка с отображением прогресса в окне
          │     └─ Перезагрузка при необходимости (после ребута UI открывается снова)
          ├─ Шаг 3: Все драйверы и апдейты готовы ->
          │     Окно «Подключите ноутбук к Mrs.team или сетевому кабелю»
          │     Непрерывный опрос контроллера rixos.rus (каждые 3 сек)
          └─ Шаг 4: Контроллер доступен -> Ввод учетных данных ->
                Add-Computer (текущее имя ПК сохраняется) -> Очистка автозапуска -> Ребут
```

## Состав файлов на флешке

```
<ФЛЕШКА>:\
├── autounattend.xml                       (создан в schneegans.de)
└── sources\
    └── $OEM$
        └── $$
            └── Setup
                └── Scripts
                    ├── SetupComplete.cmd
                    └── WinPrepare\
                        ├── Bootstrap.ps1            (первичная регистрация автозапуска)
                        ├── Common.ps1               (общие модули Wi-Fi, WUA, проверки связи)
                        ├── Config.ps1               (все настройки: SSID, пароль, домен)
                        ├── Main-UI.ps1              (главное визуальное приложение)
                        ├── WLAN_MRS.Mobile.xml      (профиль Wi-Fi WPA2-PSK)
                        └── WLAN_MRS.Mobile-WPA3.xml (профиль Wi-Fi WPA3-SAE)
```

## Чек-лист для `autounattend.xml` (генератор schneegans.de)

В конфигураторе [schneegans.de](https://schneegans.de/windows/unattend-generator/):

1. **Bypass network check (NRO)** — **ОБЯЗАТЕЛЬНО включить**:
   В Windows 11 25H2 без этого установка встанет намертво на этапе *«Давайте подключим вас к сети»*.
2. **Bypass system requirements** — Включить (TPM 2.0, Secure Boot, RAM, CPU).
3. **Product Key (Редакция Enterprise)**:
   - Укажите официальный KMS GVLK-ключ Windows 11 Enterprise:
     `NPPR9-FWDCX-D2C8J-H872K-2YT43`
   - Это гарантирует установку Enterprise и исключит блокировку скрипта заводскими OEM-ключами ноутбука.
4. **Computer Name**:
   - Задайте имя компьютера или шаблон в генераторе — именно это имя скрипт сохранит при вводе в домен.
5. **User Accounts (Локальный пользователь)**:
   - Имя: любое (например, `Admin`).
   - Группа: обязательно **Administrators**.
   - **Auto logon**: Включить (**Enable**), а поле **Count** оставить пустым или 99.
6. **OOBE screens**:
   - Отметить пропуск EULA, конфиденциальности (Privacy questions), диагностических данных.
7. **Partitioning (Разметка диска)**:
   - Установка на Disk 0 (Wipe disk 0, automatic partitions), чтобы установщик не задавал лишних вопросов.

## Копирование на загрузочную флешку

**Из Windows** (если флешка — диск `E:`, а папка с проектом в `C:\WinPrepare\usb`):
```cmd
robocopy "C:\WinPrepare\usb\WinPrepare" "E:\sources\$OEM$\$$\Setup\Scripts\WinPrepare" /E
copy "C:\WinPrepare\usb\SetupComplete.cmd" "E:\sources\$OEM$\$$\Setup\Scripts\"
```

**Из Linux** (флешка смонтирована в `/media/user/WIN11`):
```bash
mkdir -p '/media/user/WIN11/sources/$OEM$/$$/Setup/Scripts'
cp -r usb/WinPrepare '/media/user/WIN11/sources/$OEM$/$$/Setup/Scripts/'
cp usb/SetupComplete.cmd '/media/user/WIN11/sources/$OEM$/$$/Setup/Scripts/'
```

## Что увидит системный администратор

1. Вставил флешку → включил ноутбук → началась установка.
2. Программа установки размечает диск, ставит Windows 11 Enterprise, автоматически логинится на рабочий стол.
3. Прямо на рабочем столе открывается окно **WinPrepare**:
   - Подключает Wi-Fi `MRS.Mobile`;
   - Находит все накопительные обновления и **все драйверы** устройств;
   - Скачивает и устанавливает их;
   - Перезагружает ноутбук (1–3 раза в зависимости от пакетов драйверов), каждый раз автоматически возвращаясь на рабочий стол и продолжая проверку;
4. Когда обновлений больше нет, окно сообщает:
   - **«Обновления и драйверы установлены! Пожалуйста, подключитесь к Wi-Fi 'Mrs.team' или вставьте кабель»**.
   - Статус горит красным, пока `rixos.rus` недоступен.
5. Вы подключаете Wi-Fi `Mrs.team` или кабель:
   - Статус мгновенно становится зеленым: *«Связь с контроллером домена rixos.rus установлена!»*;
   - Нажимаете кнопку «Ввести в домен...» и вводите логин/пароль;
   - Компьютер входит в домен с сохраненным именем ПК, автозапуск очищается, ноутбук перезагружается;
6. Готово: компьютер встречает экраном входа в домен `rixos.rus`.

## Журналы

Все логи сохраняются локально в `C:\ProgramData\WinPrepare\`:
- `winprepare.log` — полный журнал работы интерфейса, установки драйверов и ввода в домен;
- `bootstrap.log` — журнал первичного хука установки;
- `state.json` — сохраненный этап выполнения.
